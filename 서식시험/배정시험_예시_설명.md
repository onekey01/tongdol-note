# 의뢰명단 예시 (배정시험)

**2026년 8월 23일 기준**으로 기간을 잡았습니다.
앞서 드린 `의뢰명단_예시.xlsx`는 기간이 전부 지나 있어서
배정과 홈 화면을 시험할 수 없었습니다. 이것으로 시험하세요.

| 파일 | |
|---|---|
| `의뢰명단_예시(배정시험).xlsx` | 암호 없음 |
| `의뢰명단_예시(배정시험)_암호5052.xlsx` | 암호 **5052** |

지자체가 준 서식을 그대로 복사해 썼습니다. 제목·머리글·열 순서가 실물과 같고
**사람 정보만 가짜**입니다. 개인정보가 한 글자도 들어 있지 않습니다.

### 사람별로 노린 것

| 사람 | |
|---|---|
| **김순자** | 서비스 셋(식사·가사·이미용)이 모두 진행중 → **서비스마다 담당을 다르게** 붙여 보세요 |
| 장병철 · 임두심 | 하나는 진행중, 하나는 끝남 → 목록에서 끝난 것만 회색 |
| 한상근 · 서만복 · 신춘자 | **받는 것이 전부 끝남** → 홈 화면에 뜹니다. 종결·중단·연장을 눌러 보세요 |
| 오귀남 | 끝났다가 2차수에서 다시 들어옴 (「종결 뒤 재이용」) |

| 배옥분 | 목록에 없는 서비스명 「말벗지원」 → **확인필요**로 걸립니다 |

## 이렇게 해보시면 됩니다

0. 검은 창에서 **`bun run 예시종사자`** — 제공인력 세 명이 한 번에 들어갑니다
   (최돌봄·해남읍 / 김손길·현산면 / 정보람·송지면, 비밀번호는 셋 다 `care1234`).
   예시 대상자들의 읍면동에 맞춰 놨으니 배정할 때 「★같은 읍면동」이 실제로 뜹니다.
   이미 있는 아이디는 건드리지 않고 지나갑니다.
1. **의뢰 접수** 에서 시트 두 장을 차례로 올려 반영
2. **홈** — 기간이 끝난 세 분이 뜹니다. 한 분은 종결, 한 분은 연장을 눌러 보세요
3. **종사자** — 세 사람이 들어와 있는지 확인 (정보람 님은 사무직원 겸직 · 별도관리)
4. **대상자 → 김순자** — 받는 서비스 세 줄에서 「담당 붙이기」로 각각 다른 사람 지정
5. **종사자 → 그 사람** — 방금 붙인 것이 「맡고 있는 대상자」에 그대로 있는지
6. **배정·주간계획** — 같은 내용이 여기에도 보이는지

3·4·5·6 은 **같은 자료를 세 화면에서 보는 것**입니다.
어느 쪽에서 고쳐도 나머지 둘에 바로 반영됩니다.

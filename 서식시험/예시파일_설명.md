# 의뢰 명단 예시 파일

지자체가 준 **서식 파일을 그대로 복사**해서 만들었습니다.
제목·머리글·표 모양·열 순서가 실물과 같고, **사람 정보만 가짜**입니다.
개인정보가 한 글자도 들어 있지 않으니 마음 놓고 시험하셔도 됩니다.

| 파일 | |
|---|---|
| `의뢰명단_예시.xlsx` | 암호 없음 |
| `의뢰명단_예시_암호5052.xlsx` | 암호 **5052** (암호 푸는 기능 시험용) |

---

## 무엇을 시험할 수 있나

판정 다섯 가지가 **모두 한 번씩 나오도록** 일부러 짜 넣었습니다.
차수를 **1 → 2 → 3 순서로** 올려야 아래 숫자가 나옵니다.

### 1차수 — 통합돌봄(4.21.) · 35줄

```
신규 20 · 추가 15 · 변경 0 · 유지 0 · 확인필요 0
```

- 처음 올리는 것이라 사람은 모두 **신규**, 같은 사람의 두 번째 서비스부터는 **추가**
- **16줄에 「15줄과 같은 사람·같은 서비스입니다」** 가 뜹니다
  (조종만 님의 안전생활환경개선이 「안전바 설치」·「가스타이머콕 설치」로 두 줄)
  → 지자체가 항목별로 나눠 적은 것일 수도, 실수일 수도 있어 **막지 않고 알려만 줍니다**

### 2차수 — 통합돌봄(5.4.) · 16줄

```
신규 4 · 추가 11 · 변경 0 · 유지 0 · 확인필요 1
```

- 1차수에 있던 사람에게 서비스가 하나씩 더 붙습니다 → **추가**
- 처음 오는 네 사람 → **신규**
- **18줄 「말벗지원」이 확인필요**로 잡힙니다
  우리 서비스 목록에 없는 이름이라 프로그램이 짝을 못 짓습니다.
  이런 줄은 **반영에서 자동으로 빠집니다.** 설정에서 서비스를 추가하거나,
  지자체에 확인한 뒤 다시 올리시면 됩니다.

### 3차수 — 통합돌봄(5.11.) · 20줄

```
신규 0 · 추가 9 · 변경 11 · 유지 0 · 확인필요 0
```

**변경 11건**이 이 예시의 핵심입니다. 이렇게 보입니다.

```
김순자  식사지원  기간 시작 2026-04-21→2026-05-11 / 기간 끝 2026-06-30→2026-07-17 / 주기 주 2회→주 3회
박영수  식사지원  기간 시작 ... / 본인부담 본인부담금 20%→면제
```

지금 두 명단을 눈으로 대조하시던 일이 이 표 한 장으로 끝납니다.

### 그다음 — 1차수를 한 번 더 올려보세요

```
신규 0 · 추가 0 · 변경 11 · 유지 24 · 확인필요 0
```

- **유지 24** — 두 번 넣어도 늘어나지 않습니다
- **변경 11** — 3차수에서 바뀐 것들이라, 1차수 내용으로 되돌리려는 셈이 됩니다.
  그래서 「변경」으로 잡힙니다. **이럴 때는 반영하지 마세요.**
  체크를 풀거나 취소하시면 됩니다.

**최종: 대상자 24명 · 의뢰 70건**

## 실물 파일로 넘어가실 때

이 예시로 확인이 끝나면, **개인정보가 살아 있는 실제 파일**로 한 번 돌려보셔야 합니다.
예시가 못 잡는 것들이 실물에 있을 수 있습니다.

- 이름이 같은 사람이 두 명 (생년월일로 갈립니다)
- 성명에 공백이 들어간 경우 (`김 순자`)
- 생년월일이 `380411` 처럼 여섯 자리
- 서비스명이 우리 목록과 조금 다른 경우

**미리보기 단계에서는 자료함에 아무것도 쓰지 않습니다.** 실물 파일을 올려서
판정만 보고 「취소」를 눌러도 됩니다. 그렇게 먼저 확인해 보세요.

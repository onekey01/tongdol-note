1. Supabase 대시보드 → 왼쪽 **SQL Editor**
2. `001_기틀.sql` 을 **통째로 복사**해서 붙여넣기
3. **Run** (Ctrl+Enter)
4. 아래에 `Success. No rows returned` 가 나오면 끝입니다

여러 번 실행해도 안전합니다. 이미 있는 것은 건너뜁니다.

## 무엇이 들어갔나

| 표 | 누가 올리나 | 무엇이 |
|---|---|---|
| `org` | 한 번 | 기관 번호·이름 |
| `worker` | 기관 PC | 인력 번호 · 살았나 죽었나 — **이름 없음** |
| `worker_device` | 등록할 때 | 어느 폰이 어느 인력인가 |
| `job` | 기관 PC | 오늘 갈 곳 — 전부 `payload_enc` 안에 잠겨서 |
| `report` | 휴대폰 | 시작·종료 시각 + 일지·서명(잠김) |
| `photo` | 휴대폰 | 사진 자리 (파일도 잠김) |

**성명·생년월일·주소·연락처를 담는 칸이 하나도 없습니다.**
지울 수 있는 칸이 아니라, 처음부터 만들지 않았습니다.

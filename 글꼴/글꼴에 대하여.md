# 글꼴

## 무엇인가

PDF 로 나가는 종이(본인부담금 청구서 · 서비스 제공·이용 계약서)에 쓰는 한글 글꼴입니다.

- `NanumGothic-ko.ttf` — 본문
- `NanumGothicBold-ko.ttf` — 굵은 글씨

## 왜 프로그램 안에 넣어 두는가

PDF 는 **글꼴을 파일 안에 같이 넣어야** 글자가 보입니다.
안 넣으면 받는 쪽 컴퓨터에 그 글꼴이 있어야 하는데, 없으면 네모(□□□)가 됩니다.
지자체 담당자나 어르신 가족이 받아 볼 때 글자가 깨지면 안 되므로 넣어 둡니다.

프로그램(`.exe`)을 만들면 이 글꼴이 **exe 안에 같이 들어갑니다.**
기관 PC 에 글꼴을 따로 깔 필요가 없습니다.

## 원본에서 무엇을 바꿨나

나눔고딕 원본은 한 벌에 4.6MB 입니다. 필요한 글자만 남겨 **1.26MB** 로 줄였습니다.

남긴 것 —

- **한글 음절 11,172자 전부** (가 ~ 힣). 어떤 이름·주소가 와도 글자가 있습니다
- 한글 자모 (ㄱ ~ ㅣ)
- 영문·숫자·문장부호 (ASCII)
- 기호 — ※ ★ ○ ● □ ■ △ → ← ㎡ ℓ ₩ ① ~ ⑳ 등
- 서식에 드물게 나오는 한자 몇 자 (年月日時分秒男女歲第號)

### 기호 글꼴 — `Symbols-ko.ttf` (4KB)

관공서 서식에는 **☑ ☐** 같은 글자가 그대로 박혀 있습니다. 나눔고딕에는 이 글자가 없습니다.
처음에는 없는 글자를 「□」로 바꿔 찍었는데, **그건 제출 서식의 글자를 우리가 바꾸는 것**입니다.
그래서 그 기호들만 담은 4KB짜리 글꼴을 하나 더 넣었습니다 (DejaVu Sans 에서 잘라 냄, 역시 자유 배포).

담긴 것 — `☐ ☑ ☒ ○ ● ◎ ◇ ◆ □ ■ △ ▲ ▽ ▼ ✓ ✔ ✕ ✖ ★ ☆ ※ → ← ↑ ↓ ↔ ⇒ ⇔`

글자마다 **어느 글꼴로 찍을지 갈라서** 찍습니다 (`server/pdf.ts` 의 `조각내기`).
두 글꼴 모두에 없는 글자(이모지, 일반 한자 등)만 **「□」로 찍힙니다** —
소리 없이 사라지는 것보다 눈에 보이는 편이 낫기 때문입니다.

## 만드는 법 (다시 만들 일이 생기면)

파이썬 `fonttools` 로 잘랐습니다. 기관 PC 에서는 필요 없고, 글꼴을 바꿀 때만 씁니다.

```
pip install fonttools
pyftsubset NanumGothic.ttf --text="(남길 글자들)" --output-file=NanumGothic-ko.ttf \
  --layout-features= --no-hinting --desubroutinize \
  --drop-tables+=GSUB,GPOS,GDEF,DSIG,LTSH,VDMX,hdmx,kern
```

OFL 은 글꼴을 프로그램에 넣어 함께 배포하는 것을 허용합니다.
다만 **글꼴만 따로 떼어 팔 수 없고**, 고쳐 쓸 때 원래 이름(Nanum)을 그대로 쓰면 안 됩니다.
여기서는 글자만 골라냈을 뿐 모양을 바꾸지 않았고, 파일 이름에 `-ko` 를 붙여 두었습니다.
